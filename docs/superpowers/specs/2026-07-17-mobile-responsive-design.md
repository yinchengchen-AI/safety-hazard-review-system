# 移动端适配设计说明

## 目标

让安全生产隐患复核系统的现有前端在 320px 至 768px 的视口范围内可用，重点保证登录、导航、首页、隐患/任务列表、详情、导入和统计等主流程不出现不可操作的横向溢出或被固定布局挤压。

## 设计决策

### 1. 共享壳层

- 桌面端继续使用左侧固定导航和可折叠侧栏。
- `max-width: 767px` 时隐藏固定侧栏，顶栏增加菜单按钮并打开 `Drawer`；菜单项沿用现有权限过滤和路由，不新增业务入口。
- 手机顶栏隐藏面包屑文字和用户名，仅保留菜单、通知、头像，避免抢占宽度。
- 内容区在手机端移除桌面的大外边距和 24px 内边距，保留白色内容面和安全区间距。
- 通过 `useEffect` 监听 `window.matchMedia`，在 SSR 与客户端首屏之间保持稳定默认值，避免手机端先渲染桌面侧栏后跳动。

### 2. 数据密集页面

- 列表筛选工具条使用可换行布局，小屏输入控件默认占满可用宽度，按钮保持至少 44px 可点按高度。
- 表格保留完整列信息并设置 `scroll.x`，让用户横向查看而不是压缩成不可读的窄列；分页在小屏使用紧凑布局。
- 审计日志、批次历史、任务详情等高列数表格沿用横向滚动，不改业务字段和排序。

### 3. 统计、详情与表单

- 首页和统计页的指标栅格通过 Ant Design 响应式 `xs/sm/md` 配置，从四列降为两列或单列。
- `Descriptions` 在手机端统一单列，长文本自然换行。
- 详情页和导入页的操作区允许换行；弹窗/抽屉在手机端接近全宽，避免内容被压缩。
- 登录卡片使用 `width: min(420px, 100%)`，并缩小手机端页面内边距。

## 样式系统

新增 `src/app/globals.css`，集中定义移动断点、内容容器间距、表格/筛选器和 Ant Design 弹层的移动端覆盖；页面仅保留与业务语义相关的局部样式，避免重复媒体查询。

## 验证标准

- 320px、375px、768px 和桌面视口下均能完成登录后的导航切换。
- 首页、隐患列表、任务列表、统计和详情页无页面级横向滚动；表格内部横向滚动仅出现在列数确实超出屏幕的区域。
- `npm run lint` 与 `npm run build` 通过。
- Playwright/浏览器手动检查抽屉导航、通知下拉、列表行点击、详情返回和移动端表单弹层。
